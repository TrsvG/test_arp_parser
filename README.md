# ARP Parser

Парсер пакетов протокола ARP на языке C. Считывает бинарные данные, проверяет их на соответствие структуре ARP и выводит содержимое полей в читаемом виде.

## Структура ARP пакета
Парсер обрабатывает стандартный пакет длиной 28 байт со следующей структурой:

| Поле | Размер | Описание |
| :--- | :--- | :--- |
| Hardware type | 2 байта | Тип сетевого протокола (Ethernet = 1) |
| Protocol type | 2 байта | Тип межсетевого протокола (IPv4 = 0x0800) |
| Hardware size | 1 байт | Длина MAC-адреса (6 байт) |
| Protocol size | 1 байт | Длина IP-адреса (4 байта) |
| Opcode | 2 байта | Операция: Request (1) или Reply (2) |
| Sender MAC | 6 байт | MAC-адрес отправителя |
| Sender IP | 4 байта | IP-адрес отправителя |
| Target MAC | 6 байт | MAC-адрес цели |
| Target IP | 4 байта | IP-адрес цели |

## Сборка и запуск
Собирается с помощью `Makefile`. 
Требования Linux/macOS.

### Команды:
all clean test gcov_report check_style format_style valgrind rebuild

### Запуск:
Для работы требуется файл с бинарными данными (по умолчанию `arp_test.bin`).
